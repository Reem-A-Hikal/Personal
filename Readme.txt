# Amera Yaseen — Textile Designer Portfolio

A fast, framework-free portfolio website for **Amera Yaseen**, a textile design engineer specializing in sublimation and digital print pattern design.

**Live site:** https://reem-a-hikal.github.io/Personal/

---

## About

This site showcases Amera's work across furniture, women's, and kids' fashion textile prints, alongside her resume, services, and contact details. It's built as a deliberately lightweight, vanilla HTML/CSS/JS site — no framework, no build step, no unnecessary dependencies.

## Tech Stack

- **HTML5** — semantic markup, one page per section
- **CSS3** — a custom design-token system (`main.css`);
- **Vanilla JavaScript** (`custom.js`, single file) — no jQuery, no vendor animation libraries
- **Bootstrap 5** — grid + icon font only (no Bootstrap JS bundle)

## Features

- Fully responsive, mobile-first layout
- Light/dark mode toggle
- Filterable portfolio grid (furniture / women's / kids' fashion)
- Custom lightbox for portfolio images
- SEO: per-page meta descriptions + Open Graph tags
